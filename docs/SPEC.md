# Accepted defaults and design tree
User requested recommended defaults and no optional questions; this supersedes the interview pauses in Grill with Docs. Goal → authentic continuous side-on fighting → fixed 60Hz deterministic simulation with a canvas presentation → two original robots, one original foundry arena, a usable AI, first-to-two rounds.

Combat → arrows or WASD move, up jumps, down crouches; J/Enter punch and K/Right Shift kick. Back blocks standing/jump attacks, down-back blocks standing/low attacks; jumps cannot block. Forward+punch at close range throws. Down → down-forward → forward + punch triggers Arc drive within 30 ticks, mirrored by facing. Standing directional punch/kick, crouching punch/sweep and airborne normals vary in range/startup/damage. One attack per jump. Legal actions respect startup, active, recovery, hitstun, blockstun, knockdown and stun. Bodies cannot overlap on the ground; jump crossups change facing. Separate integrity/stability. No energy or cooldown ability buttons.

Match → 60-second rounds, first to two, ties replay. AI approaches, guards, retreats, jumps, uses sweeps, throws and specials with visible commitment and reaction delay. Local record saves only completed match totals under rivet-circuit:v1; rematch resets combat. Pause and blur clear held inputs. Audio is synthesized, muted via visible toggle. Desktop keyboard target.

Test seams (user requested behavioral categories): exported simulation tick and inputs, AI input selection, record serialization. Test movement/facing, attacks and illegal states, hit/block heights, collisions, throws, motion recognition/mirroring/expiry, knockdown/stun, rounds/match, AI, invalid and unavailable storage. Native Mac play separately verifies presentation, input and complete match. Independent standards and fidelity reviewers compare against this spec and cited research.
